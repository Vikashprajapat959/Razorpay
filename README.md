## Overview

This project is a frontend recreation inspired by the public Razorpay marketing website. It focuses on building a polished fintech-style landing page with a navigation bar, product sections, feature illustrations, calls to action, and a multi-section layout.

It is intended as a **frontend learning and portfolio project**. A deployed preview is available at [Live Demo](https://vikash-razorpay-landing.netlify.app/). This is not the official Razorpay website and it does not process payments.

## UI Sections

- **Navigation:** product links, resources, support, pricing, and account call-to-actions.
- **Hero section:** headline, primary actions, and supporting illustration.
- **Payment suite:** payment-gateway and payment-link content.
- **Business banking:** banking-focused product presentation.
- **Product features:** feature highlights and supporting icons/illustrations.
- **Social proof and CTA sections:** customer-oriented content and closing call-to-action.
- **Footer and supporting assets:** brand-style icons and related visual elements.

## Tech Stack

| Technology | Use |
|---|---|
| HTML | Page structure and content |
| Tailwind CSS | Utility-first styling |
| Vite | Local development server and asset handling |
| SVG / PNG / JPG assets | Product illustrations, icons, and visual sections |
| Feather Icons CDN | Icon rendering used by the page |

## Run Locally

### Prerequisites

- Node.js and npm
- Git

### Setup

```bash
git clone https://github.com/Vikashprajapat959/Razorpay.git
cd Razorpay
npm install
npm run start
```

Open the local URL shown by Vite in your terminal (usually `http://localhost:5173`).

## Project Scope

- This repository demonstrates frontend layout and styling practice.
- Buttons and navigation items may be visual/demo interactions rather than connected product flows.
- No real payment gateway, merchant account, authentication service, or payment API is integrated.
- The design is an independent educational recreation and is not affiliated with or endorsed by Razorpay.
